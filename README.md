# DockReflections16

Standalone dock icon reflections for iOS 16 rootless jailbreaks. Intended to work with or without SnowBoard, by reflecting the icon views actually rendered by SpringBoard.

**Early test build:** iOS 16 device testing is still needed; do not assume compatibility with every dock layout. The project has no affiliation with the original SnowBoard Dock Extension.

The `DEB` release is built automatically from the source on the `main` branch.
